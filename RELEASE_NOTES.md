Прошивка для **ESP32-C3-MINI-V1, 4 МБ flash**: реальные показания LRF-HF преобразуются в Benewake TF03, 115200 8N1, 50 Гц.

- Допустимый диапазон 5–50000 см (**до 500 м включительно**). Это программный предел, не увеличение физической дальности датчика.
- При ошибках, отсутствии или устаревании данных передаётся 0.
- Wi-Fi `lidar_bridge`, пароль `00000000`, страница `http://legion.lidar` (резерв `http://192.168.4.1`).
- Wi-Fi выключается через 5 минут после запуска; в браузере есть обратный счётчик и частоты приёма/передачи. Передача TF03 продолжается после выключения сети.
- Лидар TX → GPIO6; GPIO10 → RX полётника; общий GND. MAVLink отсутствует.

**Готовый образ:** `esp32-c3-lidar-bridge-500m.bin` — единый образ с загрузчиком и разделами. Записывать с адреса **0x0** программой с поддержкой ESP32-C3. Инструкция прилагается в `FLASH_IMAGE.md`.

**Сборка двойным щелчком:** распакуйте `esp32-lrf-tf03-source.zip`, откройте `FLASH_WINDOWS.bat` на Windows или `FLASH_MAC.command` на Mac. При первом запуске нужен интернет. Полные инструкции: `WINDOWS_FLASHING.md`, `MAC_FLASHING.md`. Существующий `Secrets.h` сохраняется.

Сборка: Arduino CLI 1.5.1, Espressif ESP32 core 3.3.11. Контрольные суммы файлов — `SHA256SUMS.txt`. Mac-сценарий проверен на физической плате; запуск на Windows пока не проверялся.
