# Готовый образ для ESP32-C3-MINI-V1

В [GitHub Releases](https://github.com/dimaystinov/esp32-lrf-tf03/releases) скачайте `esp32-c3-lidar-bridge-500m.bin` и `SHA256SUMS.txt`.

Это **единый образ всей прошивки**, включающий загрузчик, таблицу разделов и приложение для ESP32-C3 с 4 МБ flash. Адрес записи: **0x0**. Не записывайте этот файл по адресу 0x10000. Отдельный `*.ino.bin` из сборки не является таким полным образом.

1. Подключите ESP по USB и закройте монитор порта.
2. В ESP Flasher, поддерживающем **ESP32-C3**, выберите порт ESP и файл `esp32-c3-lidar-bridge-500m.bin`.
3. Если программа спрашивает адрес, укажите **0x0**, чип **ESP32-C3**, Flash Mode **DIO**, Flash Size **4MB**.
4. Нажмите Flash и дождитесь завершения и проверки записи. После загрузки перезапустите ESP.
5. Если соединения нет: удерживайте BOOT, кратко нажмите RESET/EN, отпустите BOOT, заново выберите порт и повторите Flash.

Название ESP Flasher используют разные программы: старые версии без поддержки C3 не подходят. Через esptool v5 эквивалентная команда:

```sh
python -m esptool --chip esp32c3 --port COM5 write-flash 0x0 esp32-c3-lidar-bridge-500m.bin
```

На macOS замените `COM5` на `/dev/cu.usbmodem…`. Для сборки и прошивки без установки Python используйте `FLASH_WINDOWS.bat` или `FLASH_MAC.command` из архива исходников.

В образе: реальные данные (симуляция выключена), предел **500 м включительно**, TF03 **115200 8N1 / 50 Гц**, RX лидара GPIO6, TX в полётник GPIO10. Невалидные/устаревшие данные дают 0. Wi-Fi `lidar_bridge`, пароль `00000000`, страница `http://legion.lidar`, отключение Wi-Fi через 5 минут со счётчиком. Этот образ использует стандартные настройки Wi-Fi; для своих настроек соберите исходники.

Проверка SHA-256: Windows PowerShell `Get-FileHash .\esp32-c3-lidar-bridge-500m.bin -Algorithm SHA256`; macOS `shasum -a 256 esp32-c3-lidar-bridge-500m.bin`. Сравните результат с `SHA256SUMS.txt`.
