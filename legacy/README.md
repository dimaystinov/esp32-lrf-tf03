# Legacy: MAVLink-мост

Историческая версия передавала DISTANCE_SENSOR (132) с частотой 50 Гц и HEARTBEAT (0) с частотой 1 Гц. UART0: GPIO10 TX, GPIO3 RX, сначала 57600, позднее 115200 бод. SYSID автоматически определялся из heartbeat автопилота, COMPID дальномера оставался 195. До получения heartbeat использовался резервный SYSID=42.

Wi-Fi-мост поддерживал TCP 5760 и UDP 14550, двустороннюю передачу полных MAVLink-кадров, проверку CRC, отображение heartbeat и телеметрии полётника. Существовал режим подключения к двум заданным внешним сетям с резервной точкой доступа; затем был выбран постоянный AP.

Эта функциональность удалена. В текущих исходниках нет MAVLink-библиотеки, автоопределения SYSID и TCP/UDP-моста. Текущий протокол — Benewake TF03. Идентификаторов SYSID/COMPID в нём нет. Резервные копии прежних прошивок и личные учётные данные в публичный репозиторий не включены.
